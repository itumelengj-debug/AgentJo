Memory

Facts Agent Jo remembers about you and skills you've taught it. These are injected into context so it stays personalised. Shared with the desktop app.

Permissions

Standing "always allow" rules. A command rule lets Agent Jo run any command starting with that prefix without asking; a write directory rule lets it write under that folder. These are what Full-access mode and the approval prompts grant - revoke anything you don't want here.

Tasks & Scheduler

Instructions Agent Jo runs on its own. Each run gets its own session and lands in history. The app must be running for schedules to fire.

Multi-step plans Agent Jo creates while working through bigger jobs. These are read-only - they update themselves as it makes progress.

        reports against what guessing would score.

Capabilities

        
      

      

        Everything this app can do, and — read from the audit trail and the
        files each feature creates — what has actually run on this machine.
        A capability you've never exercised isn't a capability yet; it's an
        untested assumption. Each one carries a sixty-second test.
      

      

        
      

      

    

  


  
  

    

      

        
Health

        
      

      

        What is actually working right now, and the exact next action for
        anything that isn't. If a component says it's fine here and still
        misbehaves, that's worth reporting — a dashboard that lies is worse
        than none.
      

      

        
        
        
        
      

      

    

  


  
  

    

      

        
Backup & restore

        
      

      

        One file holding everything Agent Jo has learned — memories, skills,
        playbooks, the audit trail, crew briefs, pipelines, settings and the
        document index. Databases are snapshotted through SQLite's online
        backup, so it's safe to run while the app is working. Restore verifies
        every checksum first and takes a rollback point before replacing
        anything.
      

      

        
        
        
        
      

      

        
        
      

      

      

    

  


  
  

    

      

        
Crew — specialist agents

        
      

      

        Each specialist has a standing brief, its own engine, its own
        workspace folder, and its own memory that builds up across runs. Give
        it work here or from chat; give it a schedule and it works on its own.
        Autonomy is scoped: a specialist writes only inside its own workspace.
      

      

        
        
        
        
        
      

      

      

      

    

  


  
  

    

      

        
Trends — what's new in AI agents

        
      

      

        The scout scans trending GitHub repos, Hacker News, and new arXiv
        papers, clusters them into trends, and drafts a learnable for each —
        a skill you can adopt with one click, or a build request for the
        self-improve pipeline. Nothing is adopted automatically: internet
        content never changes the agent's behaviour without your click.

Undo — file time machine

        
      

      

        Before the agent overwrites a file, the previous version is saved here.
        Diff shows what changed; Restore puts the old version back (a restore is
        itself snapshotted, so you can undo an undo). Covers the agent's own
        file writes — not run_command side effects or external MCP servers.
      

      

        
      

      

      

      

    

  


  
  

    

      

        
Audit trail

        
      

      

        An append-only record of everything the agent did — every turn (which
        engine answered), every tool call with its outcome, every autonomous
        action, and configuration changes. Entries are hash-chained, so any
        tampering with the file is detectable. Local only; toggle with the
        AUDIT setting.
      

      

        
        
        
        
        
        
        
      

      

      

          

        

          Tidy the audit trail
          
        

        

          Clearing is itself recorded — the new trail opens with an entry
          saying how much went and where, so the gap can't pass unnoticed.
        

        

          
          
          
          
        

        

      



  


  
  

    

      

        
Issues

        
      

      

        Something in Agent Jo misbehaved? Describe it and hit Capture — the report
        bundles your note with the recent conversation, the engine in use, and any
        internal errors, saved locally to problems.jsonl. Copy a report
        (or all of them) and paste it to the developer. Reports can include
        conversation excerpts, so review before sharing.
