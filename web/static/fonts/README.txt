Fonts for the Symbolic Synapse theme
====================================

Served by Agent Jo itself, so the theme works offline and no font service
sees that you opened the app. A browser only downloads them when the
Symbolic Synapse theme is on; every other theme uses your system fonts.

archivo-var.woff
    Archivo (variable: weight 400-800, width 100-125), from Google Fonts
    (github.com/google/fonts, ofl/archivo). Cut down to Latin characters
    to keep it small. Licence: OFL-Archivo.txt (SIL Open Font License 1.1).

ibm-plex-sans-var.woff, ibm-plex-mono-400.woff, ibm-plex-mono-500.woff
    IBM Plex Sans (variable) and IBM Plex Mono Regular and Medium, from
    Google Fonts (ofl/ibmplexsans, ofl/ibmplexmono). The original font data,
    unchanged apart from WOFF compression. Licence: OFL-IBMPlexSans.txt and
    OFL-IBMPlexMono.txt (SIL Open Font License 1.1; "Plex" is a Reserved
    Font Name of IBM Corp., which is why these are not cut down or altered).
